Git Bash öffnen — im Zielordner (Explorer-Adressleiste)

  1. Im Explorer zu deinem Zielordner gehen (z. B. C:\Temp\git_bare_demo — dort willst du arbeiten).
  2. Oben in die Adressleiste klicken (oder Fokus: Alt + D) — der Ordnerpfad wird markiert.
  3. Diesen Pfad einfügen und Enter:
    C:\Program Files\Git\git-bash.exe
  4. → Git Bash startet und öffnet sich in genau diesem Ordner (nicht in Program Files navigieren — nur den exe-Pfad eintippen/einfügen).

Explorer selbst: Win + E. Git fehlt? https://git-scm.com/download/win
